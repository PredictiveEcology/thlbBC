# thlbBC

Timber harvesting land base (THLB) for British Columbia study areas: the official provincial THLB where published, else derived from LandR yield tables (harvestable if total B reaches `minB` by `age`).

A SpaDES module. The calculations are in the [timberSupply](https://github.com/PredictiveEcology/timberSupply) package. See [thlbBC.Rmd](thlbBC.Rmd) for the manual.
